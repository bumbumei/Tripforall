# 함께걸음 (TripForAll) — 서비스 개요

## 한 줄 소개

> **"휠체어 할머니부터 8살 손주까지, 한 코스로 함께 걸을 수 있는 무장애·다세대 동반 여행 AI"**

---

## 문제 정의 (Problem)

한국 관광 시장은 인구·가족 구조 변화로 새로운 트렌드(**D.U.A.L.I.S.M.**)에 진입했지만, 기존 여행 서비스는 이를 따라가지 못합니다.

| 현실 | 기존 서비스의 한계 |
|---|---|
| **고령화·돌봄 가족** 증가 — 휠체어·보행보조기·임산부 등 이동약자가 가족 단위 여행에 포함되는 비중 급증 | 무장애 정보가 흩어져 있고, "동행자 전원에게 맞는" 코스 추천이 부재 |
| **3세대 동반 여행** 증가 — 조부모·부모·자녀가 같이 가는 형태 | 가장 느린 사람 기준 페이스, 세대별 관심사 충돌 해결 못함 |
| **현지인 경험·웰니스·반려동물** 등 다양한 테마 수요 | 테마별 큐레이션 없이 "관광지 리스트"만 나열 |
| 운영시간·휴무·날씨에 따른 동선 변경 필요 | 클릭한 후에야 "오늘 휴무"를 알게 됨 |

특히 **이동약자 본인이 아니라 동행 가족이 여정을 짜야 하는 경우**, 무장애 정보 + 동선 + 휴무 + 세대별 분기까지 한 번에 챙기는 도구가 없습니다.

---

## 솔루션 (Solution)

**함께걸음**은 한국관광공사 OpenAPI 14종을 통합하고, **Ennoia 플랫폼의 LLM 에이전트**를 추론 엔진으로 사용해 한 번의 입력으로 다음을 자동 생성합니다:

1. **동행자 전원의 이동수단·체력·연령**을 한 줄에 정렬한 안전 동선
2. 시·군·구 단위 **무장애 검증된 관광지·식당·휴게소**
3. **선택한 테마**(역사·자연·음식·예술·가족·축제·현지인처럼·실내·웰니스·반려동물)에 맞는 큐레이션
4. **3세대 분기 미션** — 활동적인 가족은 짧게 분기, 세대 연결 bonding 활동 1~2회
5. **체력 시뮬레이션** — 가장 느린 동행자가 30% 미만 떨어지면 자동 휴식 삽입
6. **운영시간/휴무/날씨** 자동 회피 + 변경 안내
7. **다른 조합 보기** — 같은 입력으로 새로운 코스를 즉시 재생성

평균 응답 시간 **~15초**, 무장애 인증 시설 우선, 응급실·장애인 화장실 자동 부착.

## 핵심 가치

| | 가치 |
|---|---|
| **포용성** | 휠체어(수동/전동), 유아차, 보행보조기, 저체력, 임산부, 아동, 일반 — **8종 이동수단** 동시 지원 |
| **세대 통합** | "가장 느린 사람" 기준 + 활동적인 가족 분기 + 세대 연결 미션 |
| **현장 신뢰성** | KTO 무장애 인증 데이터 + 행정안전부 식당/화장실 표준데이터 + 국립의료원 응급실 |
| **속도** | Ennoia 추론전용 preset(gpt-4o-mini) 활용 — 4~15초 내 응답 |
| **확장성** | 4개 시·도(서울·부산·제주·경기) → 전국 확대 가능 구조 |
