## 2. 공공데이터포털 인증키 복사 (필수 ④)

### 절차
1. https://www.data.go.kr 로그인
2. **마이페이지 > 개인 API 인증키**
3. **인코딩(Encoding)키** 복사 버튼 — 우리 `.env`에 있는 디코딩키와 별개
4. **디코딩(Decoding)키** 복사 버튼 — `.env.local`의 `TOUR_API_KEY` 값과 일치하는지 확인

### 폼 ④ 입력 형식 (줄바꿈)
```
인코딩키: <공공데이터포털 마이페이지에서 복사>
디코딩키: <본인 .env.local의 TOUR_API_KEY 값 그대로 (64자)>
```
> 실제 키 값은 공개 repo에 포함하지 않음. 본인 `.env.local`에서 복사.

### 폼 ③ 활용 신청자명
공공데이터포털에 등록된 **본인 회원 이름** (마이페이지 상단에 표시됨)

3. 사본 열기 → 10장 슬라이드 채우기 (`docs/submission/20-ppt-slides.md` 그대로 옮기기)

### 작성 팁
- 슬라이드 7(아키텍처)의 ASCII 다이어그램은 → 구글 슬라이드 도형(사각형/화살표)으로 다시 그리는 게 깔끔

- 결선 PT 발표 10분 — 슬라이드 9(시행착오)에 시간 가장 많이 쏟는 게 좋음 (가장 인상적)
